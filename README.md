# 🧑‍💻  Java Programs for Beginners

This repository contains **simple Java programs for beginners**, inspired by the *BroCode* style of learning — easy, practical, and fun 😄  
Perfect for students who are just starting with Java.

---

## 📌 What You’ll Learn

✔ Basic Java syntax  
✔ Input & Output  
✔ Variables & Data Types  
✔ Conditions & Loops  
✔ Methods & Functions  
✔ Arrays & Strings  
✔ Object-Oriented Programming (OOP) basics  

---

## 📂 Programs Included

- Hello World Program  
- User Input using Scanner  
- If–Else & Switch Case  
- For, While, Do-While Loops  
- Number & Pattern Programs  
- Simple Calculator  
- Arrays & String Programs  
- OOP Examples (Class, Object, Constructor)
